LEAD INTAKE TO LOAN SALE — COMPLETE PIPELINE

Every step from first contact to funded deal + broker comp collected

Business Purpose Loans Only (DSCR, Fix-Flip, Bridge, Construction, Commercial, SBA)

PHASE 1: LEAD ACQUISITION (Day 0)

Sources (ranked by cost & speed):

  1. BiggerPockets forum answers → DM → deal submission
  2. Consumer LO referral network → warm handoff
  3. Facebook investor group engagement → DM → deal submission
  4. Wholesaler partnership → buyer needs funding
  5. LinkedIn outreach → connection → deal discussion
  6. TikTok/YouTube/Reels → comment/DM → deal submission
  7. REIA meeting → business card → follow-up
  8. Agent partnership → investor client referral
  9. Property manager partnership → portfolio owner referral
  10. Website organic (SEO) → form submission
  11. AI chatbot → qualification → form submission
  12. Courthouse auction networking → bridge loan lead
  13. CPA/tax professional referral
  14. Title company referral
  15. Google Ads (when budget allows)

What you need from the lead:

  • [ ] Name, email, phone
  • [ ] Loan type (DSCR, fix-flip, bridge, construction, commercial, SBA)
  • [ ] Property type and location (state minimum)
  • [ ] Estimated value / purchase price
  • [ ] Loan amount needed
  • [ ] Credit score range
  • [ ] Investment experience level
  • [ ] Timeline to close
  • [ ] Any special circumstances (denied elsewhere, foreign national, LLC, etc.)

PHASE 2: SCENARIO ANALYSIS (Day 0 — within 15 minutes)

Automated (RPCCP Mortgage Graph):

  • [ ] Form submission hits API → mortgage_graph.py runs
  • [ ] Pass 1: Program matching against 32+ lenders
  • [ ] Pass 2: Weakness analysis (what could blow up)
  • [ ] Pass 3: Structure optimization (better deal structure)
  • [ ] Pass 4: Hidden dimensions (tax, entity, seasoning)
  • [ ] Pass 5: Paradigm shift (is this even the right loan type?)
  • [ ] Client collision: Masked report generated (no lender names)
  • [ ] Admin collision: Full lender report with comp estimates
  • [ ] Client sees report on screen immediately
  • [ ] Don gets email with contact info + admin report

Manual review (Don — within 15 minutes):

  • [ ] Read admin report
  • [ ] Verify RPCCP lender recommendations make sense
  • [ ] Check for deal-breakers RPCCP might have missed
  • [ ] Select top 2-3 lenders to submit to
  • [ ] Estimate total comp (points + YSP + ancillary)

PHASE 3: FIRST CONTACT (Day 0 — within 15 minutes of submission)

  • [ ] Call or text the lead (phone first, text if no answer)
  • [ ] Confirm the scenario details
  • [ ] Ask clarifying questions RPCCP flagged
  • [ ] Explain what you found: "Based on your scenario, you have X viable paths..."
  • [ ] DO NOT name lenders — say "lending partner" or "program"
  • [ ] Set expectations: timeline, docs needed, process
  • [ ] Send follow-up email with:
  • Summary of the call
  • Document checklist (see Phase 4)
  • Next steps
  • Your contact info

Speed wins:

  • 78% of borrowers go with the FIRST lender who responds
  • 15-minute response = industry gold standard
  • Agent-referred leads convert 15-25% vs 2-4% for cold leads

PHASE 4: DOCUMENT COLLECTION (Days 1-5)

DSCR loans (minimal docs):

  • [ ] Purchase contract or refi property address
  • [ ] Rent schedule or lease agreement (existing tenants)
  • [ ] AirDNA/Rabbu/lender rent estimate (if vacant or STR)
  • [ ] Entity docs (LLC articles, EIN letter) if applicable
  • [ ] Insurance binder (or quote)
  • [ ] Bank statements (2 months — for reserves verification)
  • [ ] Photo ID
  • [ ] Credit authorization (soft pull or lender-specific form)

Fix & Flip / Bridge:

  • [ ] Purchase contract
  • [ ] Scope of work with budget
  • [ ] ARV comps (3-5 comparable sales)
  • [ ] Contractor bids (if available)
  • [ ] Entity docs
  • [ ] Proof of experience (prior project HUDs, track record)
  • [ ] Insurance (builder's risk quote)
  • [ ] Bank statements (reserves)
  • [ ] Photo ID + credit auth

Construction:

  • [ ] Plans and specs
  • [ ] Permits (or permit timeline)
  • [ ] Contractor license + resume
  • [ ] Detailed budget/draw schedule
  • [ ] Lot ownership docs (deed, mortgage payoff if any)
  • [ ] Entity docs
  • [ ] Bank statements (reserves)
  • [ ] Insurance (builder's risk)

Commercial / Multifamily:

  • [ ] Operating statements (T-12, 2 years if available)
  • [ ] Rent roll (current)
  • [ ] Purchase contract or refi property docs
  • [ ] Entity docs (operating agreement, articles)
  • [ ] Personal financial statement (PFS)
  • [ ] Schedule of real estate owned (SREO)
  • [ ] Environmental Phase I (or budget for one)
  • [ ] Insurance quotes
  • [ ] Management agreement (if third-party managed)

SBA:

  • [ ] Business plan (for startups)
  • [ ] 3 years business tax returns
  • [ ] 3 years personal tax returns
  • [ ] Personal financial statement (SBA Form 413)
  • [ ] Business debt schedule
  • [ ] Ownership/affiliation chart
  • [ ] Franchise agreement (if applicable)
  • [ ] Lease agreement (if real estate involved)
  • [ ] Projections (for new businesses)

PHASE 5: LENDER SUBMISSION (Days 3-7)

  • [ ] Package the file per lender requirements
  • [ ] Submit to primary lender (highest comp + best fit)
  • [ ] Submit to backup lender (if primary has risk)
  • [ ] Track submission in CRM / spreadsheet:
  • Date submitted
  • Lender name
  • Program
  • Loan amount
  • Expected comp (points + YSP)
  • Status
  • AE contact
  • Expected close date

Submission checklist per lender:

  • [ ] Application completed (lender portal or form)
  • [ ] All required docs uploaded
  • [ ] Credit pulled (lender pulls, not you)
  • [ ] Appraisal ordered (lender typically orders)
  • [ ] Title ordered (coordinate with title company — referral fee opportunity)
  • [ ] Insurance binder confirmed

PHASE 6: UNDERWRITING (Days 7-21)

Track and push:

  • [ ] Monitor lender portal daily for conditions
  • [ ] Respond to conditions within 24 hours
  • [ ] Common conditions:
  • Additional bank statements
  • Explanation letters (LOE for credit events, gaps, etc.)
  • Updated rent schedule
  • VOE / VOD (verification of employment/deposits)
  • Insurance updates
  • Entity doc corrections
  • Appraisal review responses
  • [ ] Call AE if anything stalls — relationships matter
  • [ ] Update borrower weekly (even if no news — silence kills deals)

Appraisal:

  • [ ] Ordered by lender (typically $400-$600 residential, $2,000-$5,000 commercial)
  • [ ] Review appraisal when received
  • [ ] If value comes in low:
  • Request reconsideration of value (ROV) with better comps
  • Restructure deal (more down, different program)
  • Switch lenders (some have more flexible appraisal standards)

PHASE 7: CLEAR TO CLOSE (Days 14-30)

  • [ ] Receive CTC (Clear to Close) from lender
  • [ ] Review closing disclosure / settlement statement
  • [ ] Verify your comp is correct:
  • Borrower-paid origination points
  • Lender-paid YSP (confirm on HUD/CD)
  • Any ancillary fees you're collecting
  • [ ] Coordinate with title company:
  • Confirm closing date/time/location
  • Wire instructions to borrower
  • Title insurance ordered and confirmed
  • Insurance referral fee opportunity
  • [ ] Send borrower final docs to review:
  • Closing disclosure (if applicable — not required on business purpose)
  • Wire instructions (from title, NOT from you)
  • Cashier's check amount (if applicable)
  • What to bring: ID, entity docs, cashier's check

PHASE 8: CLOSING (Day 14-45 depending on loan type)

At closing:

  • [ ] Borrower signs docs at title company (or mobile notary)
  • [ ] Verify all numbers match what was disclosed
  • [ ] Confirm your comp is on the settlement statement
  • [ ] If funding same day: confirm wire from lender to title

Typical close timelines:

| Loan Type | Timeline | |-----------|----------| | Hard money / bridge | 3-14 days | | Fix & flip | 7-21 days | | DSCR | 21-30 days | | Construction | 30-45 days | | Commercial / multifamily | 30-60 days | | SBA | 45-90 days |

PHASE 9: POST-CLOSE (Day of closing + ongoing)

Immediate:

  • [ ] Confirm funding (lender wires to title, title disburses)
  • [ ] Confirm YOUR comp was disbursed (check your account within 1-3 business days)
  • [ ] Send borrower a thank-you email
  • [ ] Ask for referrals: "Know any other investors who need funding?"
  • [ ] Ask for Google review / testimonial
  • [ ] Log the deal in your tracker:
  • Loan type, amount, lender
  • Total comp collected
  • Lead source (for ROI tracking)
  • Close date
  • Borrower name + contact (for future deals)

Insurance referral follow-up:

  • [ ] Confirm insurance referral fee was paid (if applicable)
  • [ ] Track per referral partner

Second closing opportunity:

  • [ ] Fix & flip → DSCR refinance when rehab is done (6-12 months)
  • [ ] Bridge → DSCR or conventional takeout (6-12 months)
  • [ ] Construction → permanent financing (construction-to-perm)
  • [ ] Set calendar reminder for refi follow-up
  • [ ] This is COMP EVENT #2 on the same property

PHASE 10: PIPELINE MANAGEMENT (Ongoing)

CRM / Tracker must show:

  • [ ] All active leads by stage (new → contacted → docs → submitted → UW → CTC → closed)
  • [ ] Expected close dates
  • [ ] Expected comp per deal
  • [ ] Pipeline value = sum of all expected comp
  • [ ] Conversion rate by lead source
  • [ ] Average days to close by loan type
  • [ ] Refi opportunities (upcoming second closings)

Weekly review:

  • [ ] How many new leads this week?
  • [ ] How many submitted to lenders?
  • [ ] How many in UW?
  • [ ] How many closing this week?
  • [ ] What's stuck and why?
  • [ ] What referral partners sent deals?
  • [ ] What content performed (social, SEO)?

LEGAL / COMPLIANCE NOTES

  • No RMLO license needed for business purpose loans in Texas
  • No RESPA restrictions on business purpose loans (fee splitting OK)
  • No TILA/TRID disclosures required on business purpose loans
  • Broker fee agreement should be signed before any work begins
  • Anti-money laundering — know your customer (KYC) basics still apply
  • Fair lending — cannot discriminate based on protected classes
  • Do not collect SSN until lender is ready to pull credit
  • Advertising — do not claim to be a "bank" or "lender" — you are a broker/matching service
  • SBA — packaging fees capped at 5% for loans >$350K, $3K for loans <$350K
  • Securities — mezzanine/preferred equity placement may require broker-dealer registration
