PHASE 2: SCENARIO ANALYSIS — Full Operational Build-Out

From form submission to "here's what you qualify for" in 15 minutes

AUTOMATED PATH (Website → RPCCP → Report)

What happens when someone submits:

  1. Borrower fills out form on clickclickclose.click/submit.html
  2. Form data POSTs to investor API server
  3. API calls mortgage_graph.py → LangGraph pipeline starts
  4. 5 RPCCP passes run sequentially (2-5 minutes):
  • Pass 1 (cogito-2.1:671b): Program matching — which of 32 lenders qualify this deal?
  • Pass 2 (kimi-k2-thinking): Weakness analysis — what will blow up?
  • Pass 3 (qwen3.5:397b): Structure optimization — better way to structure this?
  • Pass 4 (deepseek-v3.2): Hidden dimensions — tax, entity, seasoning, flood, HOA?
  • Pass 5 (nemotron-3-super): Paradigm shift — is this even the right loan type?
  1. Two collision outputs generated:
  • CLIENT REPORT (shown to borrower): no lender names, no rate sheets, no broker comp
  • ADMIN REPORT (emailed to Don): specific lenders, pricing, comp estimates, submission strategy
  1. Client sees report on screen
  2. Don gets email with: contact info + scenario + admin report + file path

MANUAL PATH (Phone call / DM / Email → Don analyzes)

When a lead comes in through phone, DM, text, or referral (not the website form):

Step 1: Qualify the deal (2 minutes on the phone)

Ask these questions in order:

  1. "What type of property — single family, multi, condo, commercial?"
  2. "Is this a purchase or refinance?"
  3. "What's the estimated value?"
  4. "How much are you looking to borrow?"
  5. "What's your credit score range — above 720, 680-720, 640-680, or below 640?"
  6. "Is this a rental? What's the monthly rent or expected rent?"
  7. "Are you buying in an LLC or personal name?"
  8. "What's your timeline — need to close in 2 weeks, 30 days, or no rush?"
  9. "Have you been denied anywhere else?"

Step 2: Quick mental match (30 seconds)

Based on the answers, you already know:

  • DSCR if: rental property, any credit above 620, any employment type
  • Fix & flip if: purchase + rehab, plans to sell within 12 months
  • Bridge if: need to close fast, short-term hold, transitional situation
  • Construction if: ground-up build, major gut rehab
  • Commercial if: 5+ units, mixed-use, office, retail
  • SBA if: owner-occupied business property, business expansion

Step 3: Run through RPCCP (optional for simple deals)

For straightforward deals (clean DSCR, good credit, standard property), you may not need RPCCP — you know the answer from experience.

For complex deals (low credit, unusual property, denied elsewhere, multiple issues), run RPCCP:

python rpccp_mortgage.py --loan-type dscr --property-type sfr --value 350000 --loan 280000 --credit 720 --rental-income 2800 --down 20 --state TX --cloud

Step 4: Call the borrower back (if you haven't already)

Use the client report talking points. Never name lenders.
